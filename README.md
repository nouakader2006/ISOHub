TSBackground-SCCM
Modern fullscreen Task Sequence background developed in native PowerShell WinForms for Microsoft SCCM / MECM.

Designed for both WinPE and Full OS deployment phases, TSBackground replaces the standard SCCM progress interface with a modern deployment experience.

[!IMPORTANT] Change the default debug password before using TSBackground in production.

Features
Modern fullscreen deployment interface
Native PowerShell WinForms application
SCCM / MECM Task Sequence integration
WinPE and Full OS support
Real-time Task Sequence monitoring
Dynamic installation step tracker
Deployment timer preserved across reboots
Automatic SCCM progress window hiding
Password-protected diagnostic console (Ctrl + Shift + D)
Custom branding support
JSON-based configuration
Lightweight and fully customizable
🔗 Repository: https://github.com/nouakader2006/TSBackground-SCCM
